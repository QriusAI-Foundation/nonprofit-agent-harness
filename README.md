# QriusAI Nonprofit Agent Harness

An open-source AI agent harness for the nonprofit sector, built on
[Google's Agent Development Kit](https://google.github.io/adk-docs/).
Maintained by [QriusAI Foundation](https://qriusai.org/).

Status: early scaffold. Architecture and included agents are still being
decided — this repo will fill in as that work lands.
